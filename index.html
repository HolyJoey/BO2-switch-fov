BO2 Switch FOV patcher

Higher FOV (up to 160) in BO2 Requiem NX for both Zombies and Multiplayer, and an FOV slider in the game's options menu that goes just as high. Everything happens in your own browser: your files are never uploaded.

1Pick your files

There are two kinds of files, both on your SD card.

  • The game (needed): t6zm.nro (Zombies) and/or t6mp.nro (Multiplayer), from /switch/t6game/. This removes the 90 limit, so the game accepts an FOV up to 160.
  • The menu (recommended): patch_zm.ff and/or patch_mp.ff, from /switch/t6game/zone/all/. This makes the FOV slider in the game's options go up to the FOV you pick in step 2. Without it the slider stops at 90, so changing your FOV in the game sets it back to 90 or lower.

On a phone the file is saved to your Downloads (the Files app on iPhone). Copy it to the SD card from there.

2Set your FOV in the config

The patch only removes the 90 limit. You set your starting FOV with these lines. Replace any existing cg_fov lines, or add them. With the menu file patched you can also change it later in the game's options.

The FOV you pick here is also the highest value of the FOV slider in the menu files (patch_zm.ff / patch_mp.ff) from step 1. Change it, and their download is updated.

File: /switch/t6game/players/config_zm.cfg

Supported versions

    

      
FileBuildStatus

      
    

    
Newer Requiem versions work too. The page looks for the FOV code in your file by itself and only patches it when it finds exactly the instructions it expects. Those builds show up as Auto-detected until they have been tested on a Switch. If the code can't be found, the file is refused and nothing is changed.

  


  

    
What gets changed?

    
The game (.nro): the engine won't accept a value above 90 for cg_fov and cg_fov_default. At two spots one 4-byte instruction is replaced so the limit becomes 160. Nothing else changes, and the file stays the same size.

    
The menu (.ff): the options menu creates the FOV slider with a range of 65 to 90. The patch changes that 90 into the FOV you pick in step 2 (at most 160, the engine limit). These files are packed and encrypted, so the page unpacks the file, changes that one number and packs it again. The original files are signed by Treyarch, and a changed file can't keep that signature, so it's saved as an unsigned file, the same kind mods use. The game loads it the same way. The file gets a little smaller, because it's packed again.

    
Both patches only affect your own view.
