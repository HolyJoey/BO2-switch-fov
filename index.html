BO2 Switch FOV patcher

Higher FOV (120 and beyond) in BO2 Requiem NX for both Zombies and Multiplayer. Everything happens in your own browser: your file is never uploaded.

1Pick your .nro file

Take t6zm.nro (Zombies) or t6mp.nro (Multiplayer) from /switch/t6game/ on your SD card. Keep a copy of the original first.

Download patched file

On a phone the file is saved to your Downloads (the Files app on iPhone). Copy it to the SD card from there.

2Set your FOV in the config

The patch only removes the 90 limit. You set the FOV itself with these lines. Replace any existing cg_fov lines, or add them.

File: /switch/t6game/players/config_zm.cfg


  


  

    
3Back on the Switch

    
    
      
  1. Put the downloaded file back in /switch/t6game/, with exactly the same name (t6zm.nro or t6mp.nro).
    2. 
      
  2. Edit the config as shown in step 2.
    3. 
      
  3. Start the game. Zombies: play without the dlc5 mod, because it resets the FOV to 90 by itself.
    4. 
      
  4. Want to undo it? Put your original file back.

What gets changed?

    
The engine won't accept a value above 90 for cg_fov and cg_fov_default. At two spots one 4-byte instruction is replaced so the limit becomes 160. Nothing else changes: the file stays the same size, and the patch only affects your own view.
